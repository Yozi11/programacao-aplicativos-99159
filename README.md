# aula - git

## Comandos basicos

autenticar via computador local no Github:
``````
gh auth login
``````

Clonar repositorio no Github:
``````
gh repo clone nome-do-repositorio
``````

Abrie VS code:
``````

code .
``````

### Salvar no github

prepara arquivos para salvar:
``````

git add .
``````

comando para versionar (Salvar):
``````
git commit -m "mensagem"

``````
baixar atualizaçoes do github:
``````
git pull
``````


Enviar para Github:
``````
Git push
``````
